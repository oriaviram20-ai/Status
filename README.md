# שליטה – התקנה בטלפון אנדרואיד

האפליקציה צריכה כתובת אינטרנט מאובטחת (https) כדי שאפשר יהיה להתקין אותה. הכי פשוט וחינמי לעשות את זה דרך GitHub Pages. נוח יותר לעשות את השלבים 1–5 מהמחשב.

## שלב א: לשים את האפליקציה באוויר

1. פתח חשבון ב־github.com (חינם).
2. לחץ על **New repository**, קרא לו `shlita`, בחר **Public** ולחץ **Create repository**.
3. לחץ על **uploading an existing file** וגרור את כל הקבצים מהתיקייה (בלי התיקייה עצמה): `index.html`, `manifest.webmanifest`, `sw.js` ושלושת קובצי האייקון. לחץ **Commit changes**.
4. היכנס ל־**Settings** ואז ל־**Pages**. תחת Source בחר **Deploy from a branch**, בחר `main` ו־`/ (root)`, ולחץ **Save**.
5. אחרי דקה או שתיים תופיע כתובת בסגנון `https://השם-שלך.github.io/shlita/`.

הקוד ציבורי, אבל המידע שלך לא נמצא בו. כל מה שאתה מזין נשמר רק בטלפון שלך.

## שלב ב: להתקין בטלפון

1. פתח את הכתובת ב־**Chrome** באנדרואיד.
2. פתח את התפריט ⋮ ובחר **התקנת האפליקציה** (או **הוספה למסך הבית**).
3. האייקון של שליטה יופיע במסך הבית. היא נפתחת במסך מלא ועובדת גם בלי אינטרנט.
4. לחיצה ארוכה על האייקון פותחת קיצורים: תקציב ומדדים, מסמכים, ניהול החיים.

## שלב ג: להעביר את המידע

1. בגרסה שבתוך Claude: ⚙️ ואז **ייצא גיבוי**.
2. באפליקציה בטלפון: ⚙️ ואז **ייבא גיבוי**, ובחר את הקובץ.
